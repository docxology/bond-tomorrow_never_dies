# Manuscript (`projects/working/bond/tomorrow_never_dies/manuscript/`)

This is the CARVER mission manuscript. Repository-wide agent rules live in
[`../docs/agent_instructions.md`](../docs/agent_instructions.md). This file
covers manuscript-specific conventions: `{{TOKEN}}` hydration, figure
protocol, and the numbered-section layout.

## File roles

| File | Role | Tokens |
|---|---|---|
| `config.yaml` | Mission identity + paper metadata (single source) | — |
| `00_abstract.md` … `07_scope_and_related_work.md`, `99_references.md` | Prose sections; metrics are `{{TOKEN}}`s | see each file |
| `preamble.md` | LaTeX injections (AMS math) | — |
| `references.bib` | Bibliography | — |
| `SYNTAX.md` | Cross-ref / figure / citation reference | — |
| `layer_contract.yaml` | Import-boundary contract | — |

## `{{TOKEN}}` protocol

Every metric is injected from `manuscript/config.yaml` +
`src/tomorrow_never_dies/manuscript_variables.py`. You do **not** hand-author
a number in prose. `scripts/z_generate_manuscript_variables.py` resolves the
tree into `output/manuscript/`; the live gate
`tests/test_manuscript_variables.py::test_manuscript_tokens_all_generated`
fails if any `{{TOKEN}}` in a `[0-9]*.md` section is missing.

## Figures

All six figures are generated by `src/tomorrow_never_dies/figures.py` into
`output/figures/` and referenced via `@fig:label` (see `SYNTAX.md`).

## Editing protocol

1. Change behavior in `src/` (never hardcode in prose).
2. Re-run `uv run python scripts/z_generate_manuscript_variables.py`.
3. Re-run the live token gate test.
